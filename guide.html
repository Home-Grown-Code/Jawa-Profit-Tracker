Set up your profit tracker

The tracker has two parts: a static website (GitHub Pages) and a small Node.js backend (Render) that reads/writes your Google Sheet using a service account — you never share your Google password.

Step 1 — Prepare your Google Sheet

  1. Open sheets.new and create a blank spreadsheet.
  2. On the first row (tab Jawa Profit, or whatever you set as SHEET_NAME), add these headers exactly:
ID, Date, Item, Store, Total Cost, Qty PCs, Cost per PC, Sell Price per PC, PCs Sold, PCs Remaining, Revenue, Profit, Status, Notes
  • Copy the Sheet ID: it's the long string between /d/ and /edit in your sheet URL.

    • Step 2 — Create a service account

    1. Go to the Google Cloud Console, create or pick a project, and enable the Google Sheets API.
    2. Go to IAM & Admin → Service Accounts and create a service account.
    3. Create a JSON key for it and download the file. Open it — you need client_email and private_key.
    4. Share your Google Sheet with that client_email as an Editor. This is the only permission needed.

    Step 3 — Deploy the backend on Render

    1. Push this repo to GitHub (see Home-Grown-Code/Jawa-Profit-Tracker).
    2. In Render, create a new Web Service and connect this repo (or use the included render.yaml).
    3. Set these Environment Variables on Render (do not commit real values):
    • GOOGLE_SHEET_ID — your Sheet ID from Step 1
    • GOOGLE_SERVICE_ACCOUNT_EMAIL — the service account client_email
    • GOOGLE_PRIVATE_KEY — the full private key from the JSON key (keep the \n escapes)
    • SHEET_NAME — e.g. Jawa Profit (default)
    • PORT — 3001
  • Note your Render service URL, e.g. https://jawa-profit-tracker.onrender.com.
  • Check it’s running: open <your-render-url>/health — you should see {"ok":true}.

    • Step 4 — Point the website at your backend

    Open assets/js/app.js and set API_BASE to your Render URL, e.g.:

    const API_BASE = 'https://jawa-profit-tracker.onrender.com/api';

    Commit and push. GitHub Pages will redeploy the static site automatically.

    For local development, leave API_BASE as http://localhost:3001/api and run npm start in this folder.

    Using the tracker

    • Tracker tab — add an item you bought, its total cost, how many PCs (pieces), and your sell price per piece.
    • Sheet tab — edit PCs Sold, Status and Notes per row; profit and PCs remaining recalculate and write back to your Google Sheet.
    • Home tab — overview of how it works.

    Entries are appended as rows in your Google Sheet. Offline saves queue and sync when you’re back online.
